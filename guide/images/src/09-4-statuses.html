StatusWhat it meansWhat you do
loadedThe project loaded and every page was screenshotted.Open the PNGs and review them against the visual-verify skill.
validation_failedA report or semantic check failed. Desktop was not touched.Fix the listed errors in the source files, then run again.
load_failedDesktop rejected the project and showed an error dialog.Read the captured dialog text; fix the named file and line.
loaded_with_issuesDesktop loaded only after dropping broken parts. Screenshots are UNTRUSTED.Fix the reported filter expression; the instance is closed so nothing degraded is saved.
not_runningPower BI Desktop is not running (after an automatic reopen attempt).Open Template.pbip in Desktop, then run again.
no_bridgeDesktop is running but offers no bridge connection.Turn on the Desktop Bridge setting (Section 07) and restart Desktop.
other_projectDesktop is running, but with a different project open.Open this project; the message names what is open instead.
bridge_unavailableThe powerbi-report-author CLI is not installed, so the report files cannot be validated.Install both npm CLIs (Section 07).
errorThe project could not be found.Run from inside the repository folder.
Green = success. Amber = skipped: the loop fails open and lets work continue, but nothing was visually verified. Red = a defect that blocks completion.
