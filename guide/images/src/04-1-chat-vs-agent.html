Normal AI chat (e.g. a chatbot website)

1. You paste in text or a question.
▼
2. It answers with text or code to copy.
▼
3. It cannot see your files unless you paste them.
▼
4. You copy the answer, edit files, run checks.
▼
5. It forgets your house rules unless you repeat them.

AI coding agent (Copilot agent / Claude Code)

1. You describe the goal, e.g. "build the page in specs/sales.md".
▼
2. It reads the repo: rule files, spec, model, pages.
▼
3. It edits files directly in your folder.
▼
4. It runs commands: validation scripts, the verify loop.
▼
5. It loads the house rules automatically every session, then reports back for your review.
