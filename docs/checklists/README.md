# Power BI Modeling Checklist Index

This folder separates the full modeling-review guidance into focused, reusable standards so teams can apply only the relevant checklist.

All checklist rows preserve:
- when applicable conditions
- Mark N/A when criteria
- quantitative thresholds
- Microsoft Learn links

- [Semantic Model and Relationships](./semantic-model-and-relationships.md) — rows 11-20, 23-27

## Usage pattern

1. Pick the checklist(s) for the current task.
2. Record each row as Pass / Needs Work / N/A.
3. If N/A, capture why the condition does not apply.
4. If Needs Work, include the threshold and remediation action.
